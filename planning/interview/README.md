# Interview ledger and companion records

These five files are the original GUI.Forms interview ledger and the records
written from it, copied verbatim from the `falseywinchnet/file_manager`
repository, `planning/gui_forms/`, at commit `867180e` (2026-08-10). They
were written while GUI.Forms was still a subtree of File Manager, so their
own cross-references use that repository's layout.

| File | Contents |
|---|---|
| `GUI_FORMS_INTERVIEW_LEDGER.md` | The owner's interview answers that govern GUI.Forms |
| `GUI_FORMS_BACKEND_DECISION_MAP.md` | Backend and renderer decisions derived from the interview |
| `GUI_FORMS_RESOURCES_AND_CONFIGURATION.md` | Resource, asset and configuration decisions |
| `GUI_FORMS_ACCESSIBILITY_AND_TEXT_ROUND_001.md` | The first accessibility and text interview round |
| `WINFORMS_CONTROL_INVENTORY.md` | The Windows Forms control inventory used by the completeness matrix |
| `RIBBON_INTERVIEW_ROUND_001.md` | The ribbon framework round (stage RB), from 2026-10-14; not part of the 2026-08-10 copy |
| `DOCKING_INTERVIEW_ROUND_001.md` | The docking and PageView round (stage DK), from 2026-10-17; not part of the 2026-08-10 copy |

They are records: amend them by adding a dated note, not by rewriting earlier
answers. Where a later decision record in `decisions/` or the current code
disagrees with them, that later source governs.
