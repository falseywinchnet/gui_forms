one dimension: a control is not complete until its ownership, defaults,

## Visual-superset gate

The framework does **not** yet claim the prototype's visual superset. Public
materials, immutable role/state themes, Card, and MasterDetailView now close
the first renderer and structural-composition tranche. The File Manager proves
one public twelve-card palette laboratory plus a four-record wide/compact DNA
decision browser whose decision/evidence/verdict records use public ReviewCard.
The gate still requires complete theme and structural-token adoption plus
density variants in B11, remaining typed specimen/disclosure/step composition in B12, richer
role/provenance/vector asset breadth beyond the keyed ImageList and image-material tranches in B13, compositing group/mask/effect breadth in B10, and
priority-responsive command overflow in B16.

## Processing rule

Each implementation tranche promotes exact rows in
`generated/WINFORMS_API_CATALOGUE.tsv` only after behavior evidence. Work should
prefer cross-cutting substrate over adding a class shell. Every partial row must
retain its open behavior here or in a more specific experiment record.
