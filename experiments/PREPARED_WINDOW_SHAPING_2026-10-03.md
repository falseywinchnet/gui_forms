# Private prepared-window shaping stage

**CANDIDATE implementation assignment, 2026-10-03:** the coordinator opened the
next source-private stage on top of the native-tested input/batch ownership
experiment. The full prepared-window consumer/session/host contract remains
unavailable. This assignment does not export an SDK type, freeze an ABI, enable
a File Manager preview format or promote the planning-only Text Editor.

The visible sibling owns the private shaper, immutable batch geometry fields,
worker-safe authority observation, focused tests and the minimum empty-input
remaining-budget correction in `shape_with_workspace`. Root owns registration,
builds, measurements, records and integration. No workers/subagents are used.
Every authored file is subject to `planning/PROGRAMMING_HOUSE_STYLE.md`, including
source review independently of spelling checks and functional tests.

The implementation candidate uses the measured reusable workspace to shape each
complete paragraph independently under one existing batch reservation. It must
retain exact font bytes/face identities, subtract total retained row geometry
from the aggregate payload/run/glyph limits, preserve input and prior state on
refusal, and transfer only a complete immutable row table after final full-key
authority/ledger validation. Cancellation is checked around native calls and
does not claim interruptible shaping or a bounded shutdown deadline.

An exhausted per-call run/glyph allowance may still accept empty text in an
already prepared workspace; nonempty input must refuse. Workspace preparation
and the older `shape_bounded` entry point retain their original limits. Empty
paragraphs retain the existing private shaping result: height equals requested
device font size, ascent/descent zero, zero runs/glyphs. These empty-row metrics
are an explicit intermediate convention, not accepted public line-box, caret,
selection or baseline policy.

Required evidence: real certified input including nonzero display/source bases,
mixed scripts and empty/EOF rows; 512-row aggregate; exact independent paragraph
geometry comparison; stale/closing/wrong-executor handling; late-row and resource
failure preserving unpublished state; retained reservation accounting; and
native integration. The private source and tests now exist. Eight focused
Windows suites pass, with a further passing shape-suite run after additional
executor and existing-output regressions. The exact scope, raw logs, reviewed
source hashes and remaining coverage limits are recorded in
`../results/prepared-window-batch-shaping-2026-10-03/README.md`.
Native macOS/Linux acceptance is pending. No whole-preview timing, public
availability or visual acceptance is established by these correctness results.

Reliable host readiness delivery, public session dispatch/adoption, renderer
replay, wrap/tab behavior, overlong paragraphs, interactive selection and
accessibility remain required later work. These are not product exclusions.
