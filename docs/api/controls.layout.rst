Layout
======

Flow, table, split, master/detail, responsive and scaled layout containers.

.. list-table::
   :class: autosummary longtable
   :widths: 35 65

   * - :cpp:class:`FlowLayoutPanel <gui_forms::FlowLayoutPanel>`
     - A container that lays its children out one after another in a row or column, wrapping onto new lines.
   * - :cpp:class:`TableLayoutPanel <gui_forms::TableLayoutPanel>`
     - A container that arranges its children in a grid of sized rows and columns.
   * - :cpp:class:`ResponsiveTrackPanel <gui_forms::ResponsiveTrackPanel>`
     - A container that divides one axis into tracks which shrink, grow and collapse in an order you set.
   * - :cpp:class:`ScaledPanel <gui_forms::ScaledPanel>`
     - A panel that places its children in a fixed design space and scales them with the panel.
   * - :cpp:class:`SplitContainer <gui_forms::SplitContainer>`
     - Two panels separated by a seam that the user drags to share the space between them.
   * - :cpp:class:`SplitterPanel <gui_forms::SplitterPanel>`
     - One of the two panes of a :cpp:class:`SplitContainer <gui_forms::SplitContainer>`, which holds that pane's content.
   * - :cpp:class:`CommandOverflowPanel <gui_forms::CommandOverflowPanel>`
     - A horizontal row of command groups that hides whole groups, in an order you set, when the row is too narrow.
   * - :cpp:class:`MasterDetailView <gui_forms::MasterDetailView>`
     - A list-and-details layout that shows both side by side on wide windows and one at a time on narrow ones.
