Bounded compression
===================

Caller-owned streaming raw-deflate and zlib decoding with finite input, output and work limits. Output is unverified until stream end.

.. cpp:class:: InflateStream final

   ``#include <gui_forms/compression/inflate.hpp>``

   The caller owns this fixed workspace (less than 64 KiB), preferably off-stack. No allocation, callbacks, exceptions or retained input/output borrows. One execution context per stream. Input, output and workspace must be disjoint. A returned prefix is unverified until stream_end; discard it on any error. Errors freeze the decoder until reset. Invalid reset leaves old state intact. final_input describes the supplied extent: repeat it with any unconsumed tail. Empty input is not EOF. Exact stream end leaves subsequent bytes unconsumed.
