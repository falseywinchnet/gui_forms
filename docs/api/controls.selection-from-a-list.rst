Selection from a list
=====================

Lists, trees, combo boxes, choice groups and breadcrumbs.

.. list-table::
   :class: autosummary longtable
   :widths: 35 65

   * - :cpp:class:`ListBox <gui_forms::ListBox>`
     - A scrolling list of text rows from which the user selects one row or several.
   * - :cpp:class:`CheckedListBox <gui_forms::CheckedListBox>`
     - A list box with a check box on each row.
   * - :cpp:class:`ComboBox <gui_forms::ComboBox>`
     - A field that shows one selected item and drops down a list of the others.
   * - :cpp:class:`TreeView <gui_forms::TreeView>`
     - A hierarchy of labelled items that the user expands, collapses and selects.
   * - :cpp:class:`ObjectView <gui_forms::ObjectView>`
     - A view of many items, shown as a grid of icons or as rows with details columns.
   * - :cpp:class:`CorrespondenceView <gui_forms::CorrespondenceView>`
     - A scrolling list of records whose rows expand to show the evidence behind them.
   * - :cpp:class:`ChoiceGroup <gui_forms::ChoiceGroup>`
     - A row of buttons from which the user picks exactly one choice.
   * - :cpp:class:`BreadcrumbTrail <gui_forms::BreadcrumbTrail>`
     - A location bar that shows the path to the current place as clickable segments.
