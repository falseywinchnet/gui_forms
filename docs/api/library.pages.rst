Pages
=====

The renderer-free page model shared by page strips, page views and docking stacks: stable page identities, order with a pinned group, cancellable selection, activation history, batches, and moving a page with its content between sets.

.. cpp:class:: PageContent

   ``#include <gui_forms/pages/types/page_set_types.hpp>``

   The content a presenter attaches to a page; for ``PageView``, the page's control subtree. The set owns the content of every page in it: ``take`` moves the content out with its record, ``put`` moves it in, and removing a page or destroying the set destroys it. A page may have no content until its presenter supplies it (late content). The derived type is the presenter's; the set only destroys it.

.. cpp:class:: PageSetBatch final

   ``#include <gui_forms/pages/page_set/page_set.hpp>``

   Groups edits into one publication. Constructing it opens a batch on the set; :cpp:func:`close <gui_forms::PageSetBatch::close>` or destruction closes it. Closing the outermost batch publishes one ``pages_changed`` when any edit applied and one ``selected_page_changed`` when the selection ends on a different page than it began. Edits inside a batch still apply one at a time: a refused edit leaves the earlier ones in place. The set must outlive the scope.
