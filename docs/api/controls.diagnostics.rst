Diagnostics
===========

Metrics, easing, typography and visual-inspection views.

.. list-table::
   :class: autosummary longtable
   :widths: 35 65

   * - :cpp:class:`EasingPreview <gui_forms::EasingPreview>`
     - A diagnostic view that animates markers along tracks to compare easing curves.
   * - :cpp:class:`MetricsView <gui_forms::MetricsView>`
     - A diagnostic panel that shows the window's runtime counters.
   * - :cpp:class:`TypographySpecimen <gui_forms::TypographySpecimen>`
     - A diagnostic view that draws a text run on its baseline and reports how its font resolved.
   * - :cpp:class:`VisualInspectorView <gui_forms::VisualInspectorView>`
     - A diagnostic panel that shows the layout, state and paint record of one control.
   * - :cpp:class:`VisualInspectorOverlay <gui_forms::VisualInspectorOverlay>`
     - A transparent diagnostic layer that outlines one control's bounds and clip.

   .. cpp:member:: std::uint64_t retained_pixels_presented

      What hosts copied to the screen (stage DP), in device pixels: four bytes each in today's 32-bit rasters. Retained presents are reported through Window::notify_presented and live-surface frames through Window::notify_live_presented, so a frame's copy cost is a number that compares across hosts. A host that does not report areas leaves the pixel and rectangle counters at zero. A live frame is one surface's new frame; the core splits its clip around overlays, and those fragments are its rectangles. Durations are split between retained and live by the pixels each copied.

      The time hosts spent only copying pixels to the screen (conversion and the native copy), retained and live together. The present durations above also cover painting and composing; this one compares the copy itself across hosts.

   .. cpp:member:: std::uint64_t engine_part_records

      The theme engine's part records (T2 plan, EnginePartTable): those live now, those made with the index fallback (an item part without a stable ID, whose record follows its position rather than the item; GIVEN H3-1), and those released because their control left the window.
