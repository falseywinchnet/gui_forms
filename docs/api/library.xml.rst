.. cpp:function:: XmlReadResult read_xml(std::string_view utf8, const XmlLimits& limits = {})

   Reads one document of the subset described in xml_types.hpp. The whole input is checked before a result is returned; on any error the result holds the error, where it was found and an empty root, and nothing else is produced. Expected faults in the input never throw. Allocation failure propagates as std::bad_alloc; the limits bound the storage a read can retain to a small multiple of maximum_input_bytes.

.. cpp:namespace:: gui_forms

``#include <gui_forms/xml/xml_writer/xml_writer.hpp>``

.. cpp:function:: XmlWriteResult write_xml(const XmlElement& root, const XmlWriteOptions& options = {}, const XmlLimits& limits = {})

   Writes root as a document that read_xml accepts under the same limits. The output is deterministic: attributes in the order given, LF line ends, options.indent_spaces per level, ``<name/>`` for an element with neither children nor text, character data on the element's own line, and the same escaping every time, so writing what read_xml returned for a written document reproduces it byte for byte. Names, values, counts and depth are validated against limits; an element with both children and text is refused with XmlError::mixed_content. On failure the text is empty.
