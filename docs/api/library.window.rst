Window, scheduling and dispatch
===============================

The retained window model, update scopes, damage, frame scheduling, the UI-thread dispatcher and per-window instrumentation.

.. list-table::
   :class: autosummary longtable

   * - :cpp:class:`UpdateScope <gui_forms::UpdateScope>`
     - A batch of changes to a window that is laid out once, when the batch ends.
   * - :cpp:class:`Window <gui_forms::Window>`
     - The retained model of one window: a tree of controls with its layout, focus, input, painting and UI thread.

   .. cpp:member:: bool contain_focus

      Contained scopes reject attempts to move keyboard focus outside their retained subtree while the scope is active. Default: ``{true}``.
