gui_forms::ColorCommand
=======================

.. cpp:namespace:: gui_forms

.. cpp:class:: ColorCommand final : public Component

   ``#include <gui_forms/commands/color_command/color_command.hpp>``

   The value command of a colour picker: a shared Command, a colour and the recent colours.

   A colour command is a ribbon value command (owner decision RB-13). It holds a
   shared :cpp:class:`Command <gui_forms::Command>`, whose identity and state it shares, and adds a typed
   colour, or none for Automatic (the program's default colour). Committed
   colours become the recent colours, most recent first, which every
   :cpp:class:`RibbonColorPicker <gui_forms::RibbonColorPicker>` bound to the command shows.

   *Status:* provisional.

   :Parameters:

      **command** : ``std::shared_ptr<Command>``
         The shared :cpp:class:`Command <gui_forms::Command>`. A null command throws ``std::invalid_argument``.

   :Properties:

      **command** : ``std::shared_ptr<Command>``, read-only
         The shared :cpp:class:`Command <gui_forms::Command>`.

      **stable_id** : ``std::string``, read-only
         The command's stable ID.

      **state** : ``CommandState``, read-only
         The command's state.

      **value** : ``std::optional<Color>``, default none
         The colour, or none for Automatic. :cpp:func:`set_value <gui_forms::ColorCommand::set_value>` is the program's change:
         it raises :cpp:func:`value_changed <gui_forms::ColorCommand::value_changed>` when the value differs and invokes nothing.

      **recent_colors** : ``std::span<const Color>``, read-only
         Recently committed colours, most recent first, without repeats, at most
         ``ColorCommand::maximum_recent_colors`` (10).

   :Events:

      **value_changed** : ``Event<const std::optional<Color>&>``
         Raised after the value changes, by :cpp:func:`set_value <gui_forms::ColorCommand::set_value>` or :cpp:func:`commit <gui_forms::ColorCommand::commit>`.

   .. rubric:: Notes

   Events arrive on the UI thread; on a commit :cpp:func:`value_changed <gui_forms::ColorCommand::value_changed>` comes first and
   then the command's ``invoked``. There is no live preview.

   .. rubric:: Examples

   A text colour command:

   .. code-block:: cpp

      std::shared_ptr<gf::Command> colour = std::make_shared<gf::Command>("doc.colour", "Font colour");
      std::shared_ptr<gf::ColorCommand> command = std::make_shared<gf::ColorCommand>(colour);
      (*command).commit(gf::Color::rgba(192, 0, 0), "doc.picker");   // dark red, now the first recent colour

   .. rubric:: Methods

   .. cpp:function:: bool commit(std::optional<Color> value, std::string_view source_id)

      The user's choice: sets the value (raising :cpp:func:`value_changed <gui_forms::ColorCommand::value_changed>` when it
      differs), moves a colour to the front of the recent colours, then
      executes the command with the given source. Returns false, changing
      nothing, while the command is disabled. Automatic is a value but not a
      recent colour.
