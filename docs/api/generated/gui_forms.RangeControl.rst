gui_forms::RangeControl
=======================

.. cpp:namespace:: gui_forms

.. cpp:class:: RangeControl : public Control

   ``#include <gui_forms/controls/range_control/range_control.hpp>``

   The shared base of controls that show a number within a bounded range.

   :cpp:class:`RangeControl <gui_forms::RangeControl>` holds a :cpp:func:`value <gui_forms::RangeControl::value>` between :cpp:func:`minimum <gui_forms::RangeControl::minimum>` and :cpp:func:`maximum <gui_forms::RangeControl::maximum>`, with the step
   sizes :cpp:func:`small_change <gui_forms::RangeControl::small_change>` and :cpp:func:`large_change <gui_forms::RangeControl::large_change>` and an :cpp:func:`orientation <gui_forms::RangeControl::orientation>`. It is the base
   of :cpp:class:`TrackBar <gui_forms::TrackBar>`, :cpp:class:`ProgressBar <gui_forms::ProgressBar>` and :cpp:class:`ScrollBar <gui_forms::ScrollBar>` (and so of :cpp:class:`HScrollBar <gui_forms::HScrollBar>` and
   :cpp:class:`VScrollBar <gui_forms::VScrollBar>`), which add the drawing and the input. A :cpp:class:`RangeControl <gui_forms::RangeControl>` on its
   own draws nothing and handles no input, so create one of those controls
   instead; use this type when code should work with any of them, for example
   to bind several of them to one application value. For a number the user
   types, use :cpp:class:`NumericUpDown <gui_forms::NumericUpDown>`.

   *Status:* stable.

         The lowest value. Setting it is the same as calling :cpp:func:`set_range <gui_forms::RangeControl::set_range>` with the

      **maximum** : ``double``, default ``100``
         The highest value. Setting it is the same as calling :cpp:func:`set_range <gui_forms::RangeControl::set_range>` with the

      **value** : ``double``, default ``0``

         remeasures the control. :cpp:class:`ScrollBar <gui_forms::ScrollBar>` sets it from its constructor

   .. rubric:: Notes

   State events describe every change and the input event describes only user
   input: observe :cpp:func:`scroll <gui_forms::RangeControl::scroll>` to react to the user, and :cpp:func:`value_changed <gui_forms::RangeControl::value_changed>` to follow
   the value whatever changed it. When the user changes the value, :cpp:func:`scroll <gui_forms::RangeControl::scroll>`
   comes first and :cpp:func:`value_changed <gui_forms::RangeControl::value_changed>` second. :cpp:class:`ProgressBar <gui_forms::ProgressBar>` takes no input, so it
   never raises :cpp:func:`scroll <gui_forms::RangeControl::scroll>`.

   Several controls can bind the same ``Value<double>``. A change made through
   one of them is checked against every bound control's range before anything
   changes, so a value that one of them cannot show is rejected everywhere.
   Give the controls compatible ranges before binding them, and unbind before
   moving a control to a range that excludes the current value.

   Between ``begin_init`` and ``end_init``, :cpp:func:`range_changed <gui_forms::RangeControl::range_changed>` and :cpp:func:`value_changed <gui_forms::RangeControl::value_changed>` are
   held back and raised once each, with the latest values, after ``end_init``.
   The value is also registered as the bindable property ``Value``, so data
   bindings and :cpp:class:`PropertyGrid <gui_forms::PropertyGrid>` can read and set it.

   The derived controls publish their own accessibility roles: ``slider`` for a
   :cpp:class:`TrackBar <gui_forms::TrackBar>`, ``progress_bar`` for a :cpp:class:`ProgressBar <gui_forms::ProgressBar>` and ``scroll_bar`` for a
   :cpp:class:`ScrollBar <gui_forms::ScrollBar>`, each with the value and the range.

   .. rubric:: Examples

   Bind a slider and a progress bar to one application value. The value wins
   when each binding starts, and afterwards all three stay in step:

   .. code-block:: cpp

      gf::Value<double> volume(40.0);
      std::shared_ptr<gf::TrackBar> slider =
          gf::make_control<gf::TrackBar>(gf::StableId("mixer.volume"));
      std::shared_ptr<gf::ProgressBar> meter =
          gf::make_control<gf::ProgressBar>(gf::StableId("mixer.meter"));
      (*slider).bind(volume);      // the slider shows 40
      (*meter).bind(volume);       // and so does the meter
      (*slider).set_value(65.0);   // volume and the meter are now 65

   Changing the range clamps the value into it, raising :cpp:func:`range_changed <gui_forms::RangeControl::range_changed>` and then
   :cpp:func:`value_changed <gui_forms::RangeControl::value_changed>`:

   .. code-block:: cpp

      std::shared_ptr<gf::ProgressBar> copied =
          gf::make_control<gf::ProgressBar>(gf::StableId("copy.progress"));
      (*copied).set_range(0.0, 250.0);
      (*copied).set_value(100.0);   // normalized_value() is 0.4
      (*copied).set_maximum(50.0);  // the value is clamped to 50

   .. rubric:: Methods

   .. cpp:function:: void bind(Value<double>& model)

      ``bind(Value<double>&)`` keeps :cpp:func:`value <gui_forms::RangeControl::value>` and an application value in step.
      The value wins when the binding starts, so the control first takes the
      value's number; after that a change on either side updates the other.
      The value must already lie within the control's range, or :cpp:func:`bind <gui_forms::RangeControl::bind>` throws
      ``std::out_of_range``, and a disposed :cpp:class:`Value <gui_forms::Value>` throws
      ``std::invalid_argument``. Afterwards, setting the :cpp:class:`Value <gui_forms::Value>` to a number
      outside the range is rejected with ``std::out_of_range``. Binding again
      replaces the previous binding.

   .. cpp:function:: void unbind() noexcept

      Ends the value binding. The control keeps its current value.

   .. cpp:function:: void increment(double delta)

      Adds a positive or negative amount to :cpp:func:`value <gui_forms::RangeControl::value>`, clamped to the range. It
      behaves like :cpp:func:`set_value <gui_forms::RangeControl::set_value>`, so it raises :cpp:func:`value_changed <gui_forms::RangeControl::value_changed>` but not :cpp:func:`scroll <gui_forms::RangeControl::scroll>`.
      A delta that is not finite throws ``std::invalid_argument``.

   .. cpp:function:: void set_range(double minimum, double maximum)

      Sets :cpp:func:`minimum <gui_forms::RangeControl::minimum>` and :cpp:func:`maximum <gui_forms::RangeControl::maximum>` together. Both must be finite and :cpp:func:`minimum <gui_forms::RangeControl::minimum>`
      must be less than :cpp:func:`maximum <gui_forms::RangeControl::maximum>`, or it throws ``std::invalid_argument``; an
      empty range is not allowed. The current value is clamped into the new
      range.
