gui_forms::FontCommand
======================

.. cpp:namespace:: gui_forms

.. cpp:class:: FontCommand final : public Component

   ``#include <gui_forms/commands/font_command/font_command.hpp>``

   The value command of a font control: a shared Command and a font choice.

   A font command is a ribbon value command (owner decision RB-13). It holds a
   shared :cpp:class:`Command <gui_forms::Command>`, so its stable ID, text, description, enabled and visible
   state are that command's, and a committed choice is announced through the
   command's ``invoked`` event. What it adds is a typed :cpp:class:`FontChoice <gui_forms::FontChoice>`: a family
   name and a size in points. An empty family or a zero size is unknown, as for
   a selection whose text mixes fonts; a :cpp:class:`RibbonFontControl <gui_forms::RibbonFontControl>` shows that field
   empty.

   *Status:* provisional.

   :Parameters:

      **command** : ``std::shared_ptr<Command>``
         The shared :cpp:class:`Command <gui_forms::Command>`. A null command throws ``std::invalid_argument``.

   :Properties:

      **command** : ``std::shared_ptr<Command>``, read-only
         The shared :cpp:class:`Command <gui_forms::Command>`.

      **stable_id** : ``std::string``, read-only
         The command's stable ID.

      **state** : ``CommandState``, read-only
         The command's state.

      **value** : ``FontChoice``, default unknown family and size
         The font choice. :cpp:func:`set_value <gui_forms::FontCommand::set_value>` is the program's change: it raises
         :cpp:func:`value_changed <gui_forms::FontCommand::value_changed>` when the value differs and invokes nothing. A family with
         invalid UTF-8 or a line break, or a size that is negative, not finite or
         above ``FontCommand::maximum_size`` (1638), throws ``std::invalid_argument``.

   :Events:

      **value_changed** : ``Event<const FontChoice&>``
         Raised after the value changes, by :cpp:func:`set_value <gui_forms::FontCommand::set_value>` or :cpp:func:`commit <gui_forms::FontCommand::commit>`.

   :Inherited:

      It also has every member of :cpp:class:`Component <gui_forms::Component>`: geometry, layout, visibility, focus, input routing, painting and disposal.

   .. rubric:: Notes

   Events arrive on the UI thread; on a commit :cpp:func:`value_changed <gui_forms::FontCommand::value_changed>` comes first and
   then the command's ``invoked``, so a handler of ``invoked`` reads the new value.
   There is no live preview (owner decision RB-13: previews on gallery
   commands only).

   .. rubric:: Examples

   A font command an application applies when it is committed:

   .. code-block:: cpp

      std::shared_ptr<gf::Command> font = std::make_shared<gf::Command>("doc.font", "Font");
      std::shared_ptr<gf::FontCommand> command = std::make_shared<gf::FontCommand>(font);
      (*command).set_value({"Portsmouth Rapids", 11.0});   // value_changed, no invocation
      (*command).commit({"Carlito", 11.0}, "doc.font-control");   // value_changed, then font's invoked
