Value setting
=============

Check boxes, radio buttons, ranges, numeric and colour editors, property grids and instrument racks.

.. list-table::
   :class: autosummary longtable
   :widths: 35 65

   * - :cpp:class:`CheckBox <gui_forms::CheckBox>`
     - A box with a caption that the user checks and unchecks.
   * - :cpp:class:`RadioButton <gui_forms::RadioButton>`
     - A round button with a caption that the user selects from a group of exclusive options.
   * - :cpp:class:`RangeControl <gui_forms::RangeControl>`
     - The shared base of controls that show a number within a bounded range.
   * - :cpp:class:`TrackBar <gui_forms::TrackBar>`
     - A slider the user drags, clicks or steps with the keyboard to pick a value in a range.
   * - :cpp:class:`NumericUpDown <gui_forms::NumericUpDown>`
     - A text field for a number, with up and down buttons that step it.
   * - :cpp:class:`DomainUpDown <gui_forms::DomainUpDown>`
     - A text field with up and down buttons that steps through a list of strings.
   * - :cpp:class:`ColorValueEditor <gui_forms::ColorValueEditor>`
     - A colour field: a swatch beside a text box that edits the colour as hexadecimal text.
   * - :cpp:class:`FlagsValueEditor <gui_forms::FlagsValueEditor>`
     - A drop-down field that edits a flags enumeration as a list of check boxes.
   * - :cpp:class:`PropertyGrid <gui_forms::PropertyGrid>`
     - An inspector that lists and edits the registered properties of the selected controls.
   * - :cpp:class:`PropertyList <gui_forms::PropertyList>`
     - A scrolling list of named settings in collapsible groups, each with a value and an optional editor.
   * - :cpp:class:`InstrumentRack <gui_forms::InstrumentRack>`
     - A wrapping row of compact editing modules, each with an enable switch, a few fields and a status line.

.. cpp:class:: PropertyValueConverterRegistry final

   ``#include <gui_forms/inspection/property_value_converter_registry/property_value_converter_registry.hpp>``

   PropertyValueConverterRegistry is an instance-owned deterministic service map from canonical names and BindingValueKind defaults to validated format/parse pairs. It bounds names and text, supports local conversion context, admits nullable/standard values, and has no process-global mutable descriptor table.


   .. rubric:: Properties

   .. cpp:function:: const PropertyConversionContext& context() const noexcept

      Returns the retained instance-local conversion context.

   .. cpp:function:: void set_context(PropertyConversionContext context)

      Validates distinct bounded UTF-8 separators and commits local formatting policy.


   .. rubric:: Methods

   .. cpp:function:: bool register_converter(std::string name, PropertyValueConverter converter)

      Canonicalizes a bounded service name, requires format and parse coverage, and inserts without replacing an existing service.

   .. cpp:function:: bool unregister_converter(std::string_view name)

      Removes a named converter and every kind mapping that referred to it.

   .. cpp:function:: void map_kind(BindingValueKind kind, std::string converter_name)

      Maps a value kind to an already registered converter.

   .. cpp:function:: void clear_kind(BindingValueKind kind)

      Removes the default converter mapping for one value kind.

   .. cpp:function:: std::optional<std::string> converter_for(BindingValueKind kind) const

      Returns the canonical default converter name for a value kind.

   .. cpp:function:: const PropertyValueConverter* find(std::string_view name) const noexcept

      Returns an immutable converter pointer for valid canonical UTF-8 names.

   .. cpp:function:: std::string format(const BindingValue& value, const PropertyDescriptor& descriptor) const

      Selects explicit or kind-default service, formats through local context, and rejects invalid or unbounded UTF-8 output.

   .. cpp:function:: std::optional<BindingValue> parse(std::string_view text, const BindingValue& current, const PropertyDescriptor& descriptor) const
