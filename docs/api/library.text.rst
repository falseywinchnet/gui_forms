   A block and the spans it holds. level is a heading's level (1 to 6) or a list item's nesting (0 for an item of a top-level list), and 0 for other kinds. quote_depth counts the block quotes around the block. marker and ordinal are a list item's: an ordered item's ordinal is the number written on its marker. alignment comes from a block attribute line before a paragraph, heading or list item. .. cpp:struct:: MarkdownSpan final

   ``#include <gui_forms/text/markdown/markdown.hpp>``

   A piece of a block's text in one style. text is the text as shown: backslash escapes and character references decoded, a soft line break as one space, a code block's lines joined by line feeds. A line break span has empty text. source is the range of the source the span comes from. Spans of a block follow the source in order and never overlap. A span whose text equals its source bytes is literal text; a character reference's source is the reference, a soft or hard line break's source is the line ending, and text the parser supplies (a code block's indentation inside a container, a code span's line ending read as a space) has an empty range where it stands. Source bytes no span covers are markup: emphasis delimiters, heading and list markers, quote markers, escapes' backslashes, link destinations, attribute lists and fences.

.. cpp:function:: PreparedTextStatus rasterize_prepared_text(const PreparedTextLayout& layout, LayoutAuthority expected, GrayTextMask& output)

   Synchronous raster only: consumes immutable prepared device glyph positions, does not shape. Caller executor owns all native FT resources for this call. Checks authority/profile before work and before replacement. Failure preserves output. Empty/space-only success has 0x0 pixels and retains logical metrics. Immutable layout may be used on a separate raster executor with exclusive access to output. Publication holds the authority lock: cancellation/desire linearizes either before commit (stale) or after a successful commit. Success does not promise that authority remains current after the call returns.

.. cpp:function:: LineBoxMetrics line_box_metrics(const ResolvedTextLayout& primary, std::optional<double> used_line_height) noexcept

   The line box of ``primary`` (a resolution of any text in the used font). The face's ascent, descent and line gap are each rounded to a whole logical pixel; ``normal`` (no used_line_height) is their sum. The leading (the gap, or a used line height's excess over the rounded ascent and descent, negative when it is less) goes half above the text, rounded down, and the rest below: Chromium's rounding, measured against Chrome 155 from 12 to 21 px (notes:planning/stages/L-layout/PLAN.md section 12.5). Without design metrics (an estimate) it uses the resolution's ascent, descent and line gap.

.. cpp:function:: double snap_text_baseline(double logical_baseline, double device_scale) noexcept

   Baselines are authored in logical coordinates. This helper rounds only the final placement to a device pixel and therefore does not change line measurement or the font identity when a window crosses displays.
