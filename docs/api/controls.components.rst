Components
==========

Nonvisual components: bindings, providers, image lists, timers and semantic feedback.

.. list-table::
   :class: autosummary longtable
   :widths: 35 65

   * - :cpp:class:`Timer <gui_forms::Timer>`
     - A component that raises ``tick`` at a fixed interval on a window's UI thread.
   * - :cpp:class:`NotifyIcon <gui_forms::NotifyIcon>`
     - An icon in the desktop's notification area, with clicks, a menu and notification text.
   * - :cpp:class:`ImageList <gui_forms::ImageList>`
     - A keyed collection of images that buttons, trees and object views share.
   * - :cpp:class:`ErrorProvider <gui_forms::ErrorProvider>`
     - A component that marks controls with validation errors.
   * - :cpp:class:`HelpProvider <gui_forms::HelpProvider>`
     - A component that attaches help text and help topics to controls and routes F1.
   * - :cpp:class:`SemanticFeedback <gui_forms::SemanticFeedback>`
     - A component that turns application events into sound cues and a bounded history.
   * - :cpp:class:`Binding <gui_forms::Binding>`
     - A two-way connection between one property of a control and one field of a :cpp:class:`BindingSource <gui_forms::BindingSource>`.
   * - :cpp:class:`BindingSource <gui_forms::BindingSource>`
     - A list of records with a current position, to which controls are bound.
   * - :cpp:class:`BindingContext <gui_forms::BindingContext>`
     - A registry of the binding sources used in one window and their currency managers.
