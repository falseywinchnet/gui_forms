Scrolling
=========

.. list-table::
   :class: autosummary longtable

   * - :cpp:class:`ScrollableControl <gui_forms::ScrollableControl>`
     - The base class for controls whose children scroll inside a viewport.
   * - :cpp:class:`ScrollBar <gui_forms::ScrollBar>`
     - A standalone scroll bar that sets a value within a range.
   * - :cpp:class:`HScrollBar <gui_forms::HScrollBar>`

   * - :cpp:class:`VScrollBar <gui_forms::VScrollBar>`
