Each control on this form keeps its own state until the program changes it, and the layout only moves the parts that changed. A label that grows by a single letter should not push its neighbour onto a new line unless the text no longer fits in the space it was given.
When the dialog opens, the first field takes the focus, the default button responds to Enter, and Escape closes the window without saving. The status bar reports the number of selected items, their total size, and the time of the last refresh in the user's local format.
Le formulaire garde chaque valeur saisie jusqu'à ce que l'utilisateur choisisse Enregistrer ou Annuler. Les étiquettes trop longues passent à la ligne suivante, mais un mot n'est jamais coupé au milieu, même lorsque la fenêtre est très étroite.
